# 파일 / 폴더 정리 도구

여러 드라이브에 흩어진 **중복 파일·동명이내용 파일·버전 표기가 잘못된 파일**을
안전하게 찾아 정리하기 위한 **로컬 전용** 도구입니다.

> 🔒 **개인정보 보호:** 모든 스캔·해시·분석은 이 PC 안에서만 이루어집니다.
> 파일의 내용은 인터넷이나 외부(Claude 포함)로 **절대 전송되지 않습니다.**

---

## 가장 쉬운 사용법 — GUI 프로그램

**이 PC에서는 `파일정리_실행.vbs` 를 더블클릭하세요.** 창 깜빡임 없이 GUI 가 바로 열립니다.
(cmd 창이 잠깐 깜빡여도 괜찮으면 `파일정리_실행.bat` 을 써도 됩니다 — 동작은 같습니다.)

> ⚠️ **왜 exe 가 아니라 .vbs/.bat?** 이 PC는 **Smart App Control 이 켜져 있어** 서명되지 않은
> `dist\파일정리.exe` 는 **실행 자체가 차단**됩니다(SmartScreen처럼 우회 불가). 그래서 Windows 에
> 기본 포함된 **서명된 `pythonw.exe`** 를 통해 GUI 를 띄우는 런처를 사용합니다.
> (`dist\파일정리.exe` 는 Smart App Control 이 꺼진 다른 PC 에서는 그대로 더블클릭으로 동작합니다.)

### 화면에서 하는 일
1. **① 스캔 및 분석** 버튼 → 결과가 목록으로 표시됩니다
2. 맨 앞 **"선택"(☑) 칸을 클릭해 체크**. 완전중복은 사본이 자동 체크되어 있습니다
   - **파일명을 클릭하면 그 파일이 열립니다**(기본 프로그램). 우클릭 = 파일 열기 / 폴더에서 보기
   - 그룹 줄을 클릭하면 그룹 전체가 한 번에 토글됩니다
3. **② 미리보기** 로 무엇이 옮겨질지 확인
4. **③ 실제 이동** → 격리폴더로 이동(영구삭제 아님)
5. 잘못됐으면 **되돌리기** 버튼으로 복원

### 창 안의 옵션 (모두 자동 저장)
- **검사할 폴더** — "폴더 추가" 버튼으로 D:\, Z:\ 등 다른 드라이브/폴더를 추가
- ☑ **삭제 대신 휴지통으로 보내기** — 켜면 Windows 휴지통으로(복원은 휴지통에서), 끄면 격리폴더
- ☑ **외장정리: 같은 드라이브에 격리** — 켜면 각 파일이 있던 **그 드라이브 안**에 격리폴더를 만듭니다.
  외장/USB 정리 시 드라이브 간 복사를 막아 빠르고 안전합니다. (휴지통 모드일 땐 무시)

자세한 안전 수칙과 외장장치 주의점은 **[안전가이드.md](안전가이드.md)** 를 참고하세요.

## exe 로 배포하기 (Smart App Control 이 꺼진 PC 용)

`exe_빌드.bat` 을 더블클릭하면 `dist\파일정리.exe` 가 만들어집니다. Smart App Control 이 꺼진 PC 에서는
exe 를 더블클릭해 바로 쓸 수 있고, 첫 실행 시 SmartScreen 경고는 **"추가 정보 → 실행"** 으로 통과합니다.

---

## 다른 PC로 옮겨 쓰기 (두 가지 방법)

**방법 A — 소스 + 자동설치 (권장, 어떤 PC든):**
1. `배포_소스.zip`(또는 프로젝트 폴더 전체)을 새 PC에 복사·압축해제.
2. **`설치.bat` 더블클릭** — Python 이 없으면 winget 으로 자동 설치하고, 필요한 라이브러리(`requirements.txt`)를 모두 설치한 뒤 환경 점검까지 해줍니다.
3. **`파일정리_실행.vbs` 더블클릭** 으로 GUI 실행.
   - winget 이 없는 구형 Windows 면 `설치.bat` 이 python.org 설치 안내를 띄웁니다("Add python.exe to PATH" 체크 후 재실행).

**방법 B — exe (설치 불필요, Smart App Control 꺼진 PC):**
- `배포_파일정리.zip` 안의 `파일정리.exe` 더블클릭. Python·라이브러리 설치 필요 없음.

> 어느 방법이든 `config.json` 의 검사 폴더가 새 PC에 없으면 **자동으로 그 PC 기준으로 재설정**됩니다. 무엇이 동작 가능한지는 `py main.py doctor` 또는 GUI 요약 탭의 "환경 점검" 으로 확인하세요.

## 명령어 사용 (CLI / 자동화용)

```bat
py main.py scan              :: 폴더 스캔 + 해시 색인
py main.py report            :: 분석 후 HTML 리포트 생성(자동으로 열림)
py main.py apply             :: decisions.json 미리보기(드라이런, 실제 이동 안 함)
py main.py apply --apply     :: 실제로 격리폴더(또는 휴지통)로 이동
py main.py undo 2026-05-31_140530   :: 해당 작업을 원위치로 복원
py main.py doctor            :: 환경 점검(어떤 선택 기능이 동작하는지·빠진 라이브러리 설치법)
```

### 전형적인 흐름
1. `py main.py scan` — 설정된 폴더를 검사하고 중복 후보의 해시를 계산합니다.
2. `py main.py report` — `data/report.html` 이 생성되어 브라우저에서 열립니다.
3. 리포트에서 정리할 파일을 **체크박스**로 고르고 하단 **"결정 내보내기"** 클릭
   → `decisions.json` 다운로드 → 이 파일을 `data/` 폴더에 넣습니다.
4. `py main.py apply` 로 무엇이 옮겨질지 **미리보기**.
5. 확인되면 `py main.py apply --apply` 로 실제 이동.
6. 되돌리고 싶으면 `py main.py undo <타임스탬프>`.

## 안전장치

- **영구 삭제 없음.** 선택된 파일은 `_정리보관\날짜시각\` 격리폴더로 **이동**만 합니다
  (원래 폴더 구조를 보존). `undo` 로 언제든 복원 가능합니다.
- **기본은 미리보기(드라이런).** `--apply` 를 붙여야 실제로 움직입니다.
- **완전중복 그룹은 최소 1개를 항상 보관** (리포트에서 보관본은 체크 불가).
- 심볼릭 링크/정션, 클라우드 전용(OneDrive offline) 파일은 건너뜁니다.
- 원본 파일은 분석 중 **읽기만** 하며 절대 수정하지 않습니다.

## 설정 (`config.json`)

첫 실행 시 자동 생성됩니다. 주요 항목:

- `scan_roots` — 검사할 폴더 목록. **여기에 D:\, F:\, Z:\ 경로를 추가하면 확장됩니다.**
- `exclude_dir_names` / `exclude_file_globs` — 제외할 폴더/파일 패턴
- `min_size_bytes` — 이 크기 미만 파일 무시 (기본 1MB)
- `quarantine_dir` — 격리폴더 위치 (기본 바탕화면 `_정리보관`)
- `use_recycle_bin` — `true` 면 휴지통으로 보냄 (`send2trash` 설치 필요)
- `quarantine_per_drive` — `true` 면 각 파일이 있던 드라이브 안에 격리폴더 생성 (외장 정리용)
- `follow_symlinks` / `skip_offline_files` — 링크 추적·클라우드 파일 스캔 여부

```
├── 파일정리_실행.vbs  ★ 이 PC용 GUI 실행기 (깜빡임 없음, 권장)

├── exe_빌드.bat       exe 다시 만들기
├── 테스트.bat         자동 테스트 실행
├── dist/파일정리.exe   exe 배포본 (SAC 꺼진 PC용)
├── tests/            자동 테스트 (test_organizer.py)
├── config.json       설정 (자동 생성)

├── 테스트_검증_결과.md 점검 이슈·테스트 결과·알려진 한계

└── data/             catalog.db, report.html, decisions.json, undo 로그
```
