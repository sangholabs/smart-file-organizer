============================================================
  파일/폴더 정리 도구  —  다른 PC에서 바로 사용하기
============================================================

[가장 쉬운 방법]  파이썬 설치 없이 바로 실행
------------------------------------------------------------
1) 이 폴더의  파일정리.exe  를 원하는 위치(예: 바탕화면)에 복사합니다.
2) 더블클릭하면 창이 열립니다. (파이썬 설치 불필요 — 전부 안에 들어 있음)
3) 처음 실행 시 파란 "Windows의 PC 보호" 경고가 뜨면
      → "추가 정보" 클릭  →  "실행" 버튼
   (서명되지 않은 개인 프로그램이라 정상입니다. 한 번만 뜹니다.)

* exe 를 둔 폴더 옆에 설정(config.json)과 결과(data) 폴더가 자동으로 생깁니다.
* 검사할 폴더는 창 안의 "＋ 폴더 추가" 로 지정하세요 (D:\, Z:\ 등도 가능).


[사용 순서]
------------------------------------------------------------
  1단계  검사할 폴더 추가  →  "스캔 및 분석"(F5)
  2단계  결과 탭에서 정리할 파일 체크 (완전중복은 자동 체크)
  3단계  "미리보기" 로 확인  →  "실제 이동"
  - 잘못 옮겼으면 "되돌리기" 로 복원
  - 📊 용량 분석 탭에서 어디가 용량을 많이 쓰는지 확인

탐지 종류:
  완전중복 / 이름같음·내용다름 / 버전이상 /
  비슷한 이미지(재압축·리사이즈) / 같은 내용 문서 / 같은 내용 압축


[안전]
------------------------------------------------------------
  - 모든 처리는 그 PC 안에서만. 파일 내용은 외부로 전송되지 않습니다.
  - 영구 삭제 없음: 정리 대상은 격리폴더(_정리보관)로 이동하며 되돌릴 수 있습니다.
  - "격리 비우기" 도 Windows 휴지통으로 보냅니다(복원 가능).


[잘 안 될 때]
------------------------------------------------------------
* 더블클릭해도 아무 창이 안 뜨고 차단되는 경우
  → 그 PC에 "Smart App Control" 이 켜져 있을 수 있습니다(드물어요).
    이때는 서명 안 된 exe 실행이 막힙니다. 두 가지 방법:
    (a) Windows 보안 > 앱 및 브라우저 컨트롤 > Smart App Control 끄기
        (주의: 한 번 끄면 다시 켜려면 Windows 재설치 필요)
    (b) 또는 파이썬으로 실행 (아래 '개발자용' 참고)

* 64비트 Windows 10/11 용입니다. (32비트/ARM/맥/리눅스 ✕)


[소스 + 자동설치로 실행 (exe 가 막히거나 다른 PC일 때 권장)]
------------------------------------------------------------
전체 폴더(또는 배포_소스.zip)를 새 PC에 복사한 뒤:
    1) 설치.bat  더블클릭
       - 파이썬이 없으면 winget 으로 자동 설치
       - 필요한 라이브러리(requirements.txt) 자동 설치
       - 마지막에 "환경 점검" 결과 표시
       (winget 이 없는 구형 Windows 면 python.org 설치 안내가 뜹니다.
        설치 시 "Add python.exe to PATH" 체크 후 설치.bat 다시 실행)
    2) 파일정리_실행.vbs  더블클릭   (또는  py app.py)

* 지금 무엇이 동작 가능한지 보고 싶으면:  py main.py doctor
  (없는 라이브러리의 기능은 자동으로 건너뛰므로, 필요한 것만 설치해도 됩니다)
